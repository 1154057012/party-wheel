# 聚会大转盘

黑金聚会大转盘。混合版、真心话、大冒险三个类别，分别可选刺激版、温和版、纯菜版，共九种组合。默认每个盘面实际展示 100 道题；指针经过的题目在转盘上方实时滚动，停下后显示最终完整内容。

## 打开

直接双击 `index.html`。所有资源均为本地文件，不需要安装依赖或登录。也可以在本目录运行 `python -m http.server 4173 --bind 127.0.0.1`，访问 `http://127.0.0.1:4173`。

## 操作

- 先选混合版、真心话或大冒险，再选刺激版、温和版或纯菜版。
- 点击中心「转一下」，或在未聚焦其他按钮时按空格。
- 正常每轮 3.8 秒。转动中再点击中心「停止」或按空格，会在约 0.55 秒内减速定格。
- 全程无音效。
- 转动期间类别与档位暂时锁定，完成后可继续转或切换。
- 跟随系统减少动态效果设置。该模式下缩短等待并直接揭晓。

## GitHub Pages

纯静态网页，无需构建。保留根目录中的 HTML、CSS、JS 和 `.nojekyll` 文件，在仓库 Settings → Pages 中选择从 `main` 分支的根目录发布。

发布代码更新时，同步修改 `index.html` 中的 `app-version` 和所有 CSS/JS 链接的 `v` 参数，避免浏览器混用旧版脚本。已打开旧版页面时，可以通过在网站链接末尾添加 `?v=新版本号` 重新加载新版。

## 本地题库管理

1. 在 3 秒内连续点击顶部英文小字 4 次。
2. 输入管理密码 `112211`。
3. 选择真心话或大冒险及对应档位，可以搜索、修改、新增、删除题目。
4. 点击「保存并应用」，当前浏览器立即使用新题库，刷新后仍保留。

每套源题库可保存 1～200 题，每道题不超过 40 字；空白和同组重复内容会阻止保存。转盘直接显示题目正文预览，抽中后在上方显示全文。混合版从两类对应档位中均匀抽取最多各 50 题；不足 50 题时按较少一方的题数等量混合。

管理页支持 JSON 备份导入、导出。导入后需点击保存才会生效；关闭未保存的草稿会提示确认。浏览器存储不可用时会明确提示，原题库不会被错误覆盖。

保存内容属于当前浏览器和网站地址，不会改动 GitHub 文件，也不会同步给其他人。本地预览与线上网站存储独立，可通过导出、导入备份转移题库。清除网站数据会移除本地修改。此密码是防误入的前端入口，不是服务端权限认证。
